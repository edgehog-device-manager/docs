    container_ready(state)

    Sets container provisioning to :completed

    Example: (%{container_provisioning: :started}) -> %{container_provisioning: :completed}

    device_mapping_ready(id, state)

    Removes a device mapping from the list of device mappings that need to be provisioned.

    The list of device mappings to be provisioned is expected to be a list of device mapping deployments in the key :device_mappings_to_provision into the state.

    Example: if id matches depl2

    (id, %{device_mappings_to_provision: [depl1, depl2, depl3, ...]}) -> %{device_mappings_to_provision: [depl1, depl3, ...]}
